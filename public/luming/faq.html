Q1. 系統主打「不存檔個資」，那我們（主辦方）要如何管理報名名單？

即時直通後台，完整保留至活動結束後 3 天。

會員在 LINE 報名後，資料會即時轉傳至主辦方的專屬加密後台。為了讓秘書有充裕的時間進行行政核，系統會免費為您保留名單 3 天。

💡 秘書貼心小提示：建議您在活動結束後，隨時登入後台使用「一鍵導出表格」功能，將最完整的 Excel 名單下載至電腦備份，讓珍貴的人脈資產 100% 掌握在社團手中。

Q2. 為什麼不蒐集會員的「手機號碼」？

極致隱私保護：會員與企業主對隱私極度敏感，免留電話能大幅提升貴賓的報名意願。

行事曆自動提醒：報名成功後可一鍵同步手機行事曆，時間、導航、Dress Code 自動鎖進手機，取代傳統的電話提醒。

Q3. 系統沒有金流功能，活動費用該如何收取？

財務風險歸零：系統純做行政統計、不經手款項，完全免除手續費抽成與撥款延遲的風險。

維持線下信任：名單確認後，主辦方可維持既有的「現場繳費」或「匯款至協會公帳」渠道，財務管轄權完全獨立。

Q4. 後台建議上傳的活動主視覺規格是什麼？

建議規格： 300 x 169 像素 (px) 的橫式圖片。

為什麼是這個尺寸？ 這是完美適配 LINE 聊天室與行動網頁的黃金比例（接近 16:9）。上傳此規格能確保圖片在所有手機上皆完美呈現、不被裁切，襯托出您社團的高端品牌美學。

💡 貼心提示：如果手邊沒有專業設計軟體，您可以直接在網頁設計工具（如 Canva）中建立「1920 x 1080」或「1280 x 720」的標準 16:9 畫布進行設計，系統會自動完美等比例縮放！

1. 個人資料的收集與授權

本服務基於 LINE 前端框架（LIFF）技術開發，我們尊重並承諾保護您的個人隱私：

  • LINE 帳號授權：當您點擊使用或登入本服務時，我們會透過 LINE 官方授權機制獲取您的 LINE 顯示名稱、頭像、以及不具唯一識別性的內部識別碼（User ID）。此資訊僅用於提供您流暢的個人化介面與登入體驗。
  • 活動報名資訊：當您參與或舉辦商會活動時，本服務絕不主動強迫您留下手機號碼、身分證字號等高度敏感個資。所有活動報名欄位均由該活動主辦單位自行設定與管理。

2. 資料的使用方式

我們收集的有限資料僅用於以下用途：

  • 辦理、統計與優化您所參與或舉辦的商會活動名單。
  • 協助您將活動一鍵同步至手機日曆（如 Google日曆、Apple行事曆）。
  • 提供本服務系統的技術維護、功能優化與客戶支援。

3. 金流與隱私安全

  • 純行政統計：本服務不串接、不經手、亦不儲存任何線上金流、信用卡或銀行帳戶資訊。所有活動費用均維持線下信任收付，確保您的資產與隱私絕對安全。
  • 資料第三方串接：本服務絕不會將您的個人資料販售、交換、或出租給任何無關的第三方。

4. 資料安全與退出權利

我們採用業界標準的安全防護措施，保護儲存於雲端後台的系統資料。
