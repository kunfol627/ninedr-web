## 建議的後續實作

保留 /services 為服務總覽，先製作 /services/seo-geo 詳頁，再依詢問及服務需求逐步補其餘；不先批次產出薄內容頁。服務詳頁有足夠獨立內容後才加 sitemap、麵包屑、導覽與內部連結；/services#seo-geo 錨點繼續可用。

SEO／GEO 詳頁建議順序：適用問題 → 適合／不適合情境 → 技術與內容交付 → 客戶需提供資料 → 實際流程 → 已授權案例或匿名交付示例 → 衡量方法與限制 → FAQ → 原有語氣的 CTA。不要捏造費用、保證排名、AI 引用次數、時程、客戶評語或合作承諾；未確認的商務細節標為待確認，不可當正式內容發布。

另：paid-media intro 仍使用「渠道」，可依既有用語偏好改為「媒介／平台」。此項為文案整理，不影響索引。
